\section*{Research Question}
Check whether SWaT already exists under \texttt{data/} in the current workspace. If it does, run a short EDA focused on KL divergence and other distribution-drift metrics between the train sequence and the test sequence.

\section*{Executive Summary}
SWaT is already present locally under \texttt{data/SWaT/} with three CSV files:
\texttt{normal.csv}, \texttt{attack.csv}, and \texttt{merged.csv}.

For the local data that is actually present, the effective split is:
\begin{itemize}
\item train sequence: \texttt{data/SWaT/normal.csv}
\item test sequence: \texttt{data/SWaT/attack.csv}
\end{itemize}

The key caveat is important: the local \texttt{attack.csv} is fully labeled \texttt{Attack}, not a mixed normal-plus-attack test stream. So the measured drift is intentionally very large because the comparison is effectively \textbf{normal-only train versus attack-only test}.

To avoid relying on one metric only, the EDA computed:
\begin{itemize}
\item histogram-based \texttt{KL(train || test)}
\item histogram-based \texttt{KL(test || train)}
\item Jensen-Shannon divergence
\item Wasserstein distance
\item Kolmogorov-Smirnov statistic
\item standardized absolute mean shift
\end{itemize}

The strongest drift features are concentrated around \texttt{AIT201}, \texttt{AIT402}, \texttt{PIT501}, \texttt{PIT502}, \texttt{PIT503}, \texttt{AIT501}, and \texttt{AIT504}.

\section*{Data Preparation}
The EDA used the local CSV files directly.
\begin{itemize}
\item Column names were stripped because some SWaT columns contain leading spaces.
\item \texttt{Timestamp} and \texttt{Normal/Attack} were excluded from feature drift calculations.
\item The remaining \texttt{51} columns were coerced to numeric.
\item Parse gaps were forward-filled and backward-filled.
\end{itemize}

This is broadly consistent with the reference SWaT loader in \texttt{M2N2}, which also loads SWaT from \texttt{data/SWaT} and applies numeric coercion plus forward fill.

\section*{Interpretation}
\begin{itemize}
\item Comparing \texttt{normal.csv} against \texttt{attack.csv} produces a strong drift signal across many features. This is expected and not surprising.
\item The strongest drift is not evenly spread across all channels. A smaller set of sensors and pressure-related channels dominates the divergence signal.
\item Comparing \texttt{normal.csv} against \texttt{merged.csv} produces only mild drift because the merged file is mostly normal data.
\item For future benchmark integration, the codebase should treat ``attack-only test'' and ``mixed-timeline test'' as two different evaluation semantics.
\end{itemize}
